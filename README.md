## Features

- Terminal UI — keyboard-driven, nvim-like navigation
- Fuzzy search verses with fzf integration
- Fast and lightweight — written in Rust
- Read any book, chapter, or verse from the CLI

## Installation

> Requires Rust and Cargo

\`\`\`bash
git clone https://github.com/mclmat19/scripture-app
cd scripture-app
cargo build --release
\`\`\`

## Usage

\`\`\`bash
cargo run
\`\`\`

Navigate with `j/k`, search with `/`, quit with `q`.
